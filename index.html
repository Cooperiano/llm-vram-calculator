How It Works

The VRAM Formula

Total VRAM ≈ Model Weights + KV Cache + Overhead

Model Weights = Parameters × Bytes per Parameter (depends on quantization)
KV Cache = 2 × Layers × KV Heads × Head Dim × Bytes per Elem × Context Tokens
Overhead ≈ max(Model Weights × 0.2, 1 GB) for CUDA context, buffers, etc.

What affects VRAM usage?

  • Model parameters — bigger model = more VRAM. This is the dominant factor.
  • Quantization — lower precision = less VRAM. Q4_K_M is ~3.5× smaller than F16.
  • Context length — longer context = bigger KV cache. At 128K tokens, the KV cache can exceed the model weights for some architectures.
  • KV cache quantization — llama.cpp supports quantizing the KV cache to Q8_0 or Q4_0, dramatically reducing memory for long contexts.
  • Inference engine — vLLM, llama.cpp, Ollama, and Transformers all have different memory profiles.
  • Batch size — serving multiple concurrent requests increases KV cache proportionally.

FAQ

How accurate is this calculator?

It gives a reasonable estimate (± 15%) for single-batch inference with llama.cpp / Ollama. The model weights calculation is exact for a given quantization. The KV cache estimate uses approximate architectural constants. Overhead is a heuristic. For precise numbers, load the model and check nvidia-smi or ollama ps.

Can I run Llama 3.1 70B on a single 4090?

Yes, with Q2_K quantization (~22 GB model weights) or IQ4_XS (~37 GB split across two 4090s). With Q4_K_M you need ~40 GB for weights alone, so you'd need at least two 24 GB GPUs or an Apple Silicon Mac with enough unified memory.

Why does context length matter so much?

The KV cache stores keys and values for every previous token. At 128K context with FP16 KV cache, this can add 10–30+ GB depending on model architecture. This is why KV cache quantization (Q8_0, Q4_0) is critical for long-context inference.

What about Flash Attention?

Flash Attention reduces peak memory usage during prefill but stores the full KV cache. It helps with throughput but not the steady-state VRAM requirement shown here.

Does speculative decoding affect VRAM?

The draft model adds its own modest VRAM cost. A 0.5B draft model at Q4_K_M adds ~300 MB. The target model's VRAM requirement is unchanged.
